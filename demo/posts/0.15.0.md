# tuiboard 0.15.0: X drafts and a content backlog

Drafts. Nothing here is posted automatically; review the media in `demo/out/` first
(`bun run demo:shots` regenerates all of it). Everything on screen is the invented demo
environment, and the Agents pane shows invented sessions from the four harnesses tuiboard reads
(Claude Code, Codex, OpenCode, Pi).

Two shapes of picture: **landscape 1920x1080** (the whole dashboard) and **portrait 1080x1350**
(a single pane, as it looks in a narrow terminal or a herdr pane). Clips are MP4 (X, LinkedIn)
and GIF (README, anywhere that autoplays).

## 2. Evergreen backlog

Standalone posts, any order, any week. Each has one picture or clip.

**The whole thing.** Media: `images/hero.png`

>

**Agents.** Media: `video/filter.mp4`

Alt: A list of ten agent sessions, then the list filtered to each harness in turn.

**Agents, still.** Media: `images/agents.png`

> Status at a glance: busy, blocked on you, done, idle, stale. Two lines per session, with model,
> branch and folder.
>
> tuiboard reads the sessions the agents already keep on disk. No plugin, no server.

**Grab a card.** Media: `video/grab.mp4`

> Moving a card between columns: `g` to grab it, h/l to carry it, `g` to drop it.
>
> No mouse, and it works in a 60-column terminal.

Alt: A task is grabbed in the Todo column and carried to the Doing column.

**Today / Tomorrow.** Media: `video/planner.mp4`

> The daily triage loop in three keys.
>

## 3. Notes for posting

- Pair a clip with one sentence and the install line. The clips speak for themselves.
- The demo environment makes the on-screen names safe (Sam, Mia, Priya, nimbus.app); no real board,
  path or session ever appears.
- Check the release is live (`npm view tuiboard version`) before any "is out" post.
- Nothing here is scheduled or sent by the tooling. Posting is by hand.
