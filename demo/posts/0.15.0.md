# tuiboard 0.15.0: X drafts

Drafts, never posted automatically. Media comes from `bun run demo:shots` (`demo/out/`).
Everything on screen is the invented demo environment.

## Main post: release

Media: `video/drag.mp4` (or `images/hero.png` if a still is better for the timeline)

> tuiboard 0.15 is out.
>
> Your day is a ruler now. Double-click a block in the terminal, drag it to move it, drag its
> bottom edge to resize it. 15-minute steps, all in the TUI.
>
> npm i -g tuiboard

Alt text: A terminal window showing a day agenda. A block is selected with a double click,
dragged down the hour ruler, then stretched by its bottom edge.

## Reply 1: the tray

Media: `video/tray.mp4`

> Tasks with no hour wait in a "To place" tray at the top of the Agenda.
>
> Double-click one to arm it, click the slot where it goes, nudge it with j/k. Or skip the
> mouse: `c` arms it and the first j/k drops it in the first free half hour.

Alt text: A task is armed from the tray, placed on the 08:00 slot with a click, moved down two
rows with the keyboard and kept with Enter.
